PHONE-READY CAKE ORDER APP

This is a mobile web app/PWA. Extract the ZIP and upload these files to an HTTPS static website (for example GitHub Pages). Open the site in Chrome on Android and choose Chrome menu > Add to Home screen.

It includes cake browsing, details, cart, quantity controls, checkout, delivery form, payment option display and order confirmation.

It is a prototype: no real payment processing or online bakery database is included.
